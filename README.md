# Посмотри в окно

Учебный проект Яндекс Практикума. Приложение показывает видео из разных городов и позволяет искать их по городу и времени суток. В рамках проекта оформлен интерфейс по макету Figma.

Для запуска откройте `index.html` в браузере. Для загрузки видео нужен доступ к API Практикума.

[Репозиторий проекта](https://github.com/i-show-nikitka/posmotri-v-okno-ad)
